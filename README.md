# RSMP core specification
RSMP is an open, modern and flexible communication protocol primarily suited for communication between road side equipment and supervision systems.

This repository contains the RSMP Core specification which defines the basic message format and behaviour common to all types of equipment and systems.

RSMP uses Signal exchange lists (SXL) for specific types of functionality or equipment, including the component types and alarms, status and commands messages.
SXLs are defined in other repositories.

## Content
The documentation is written in reStructuredText (reST) format.
HTML and PDF versions can be built using Sphinx, see [BUILDING.md](BUILDING.md).

You can view all RSMP specification online at https://rsmp-nordic.org/specification/
