# Security
RSMP is a protocol used for communication between roadside equipment and central systems. Safety and integrity are often very important for this type of equipment, e.g., traffic lights and variable message signs.

Roadside equipment, and embedded systems in general, can face physical, network, or software attacks.

Common vulnerabilities in embedded systems include lack of software updates, weak encryption, and insufficient access controls.

## Elements of Embedded Device Security
Best practices for embedded device security should be implemented by manufacturers, road authorities, and IT departments, but are not directly related to RSMP:

- Secure Boot Process
- Secure Firmware Updates
- Strong Encryption
- Strong Authentication and Access Controls
- Secure Network and Communication
- Monitoring and Auditing

The RSMP protocol can utilize encrypted communication through TLS (Transport Layer Security); however, TLS, encryption, authentication, and access control are separate from RSMP.

## Ensuring Best Practices
Ensure security in embedded devices with practices like:

- Security-First Design Approach
- Multi-Layered Security Strategy 
- Regular Testing and Updating of Security Measures
- Compliance with Industry Standards and Regulations 
- Collaboration with Security Experts and Vendors

These types of process recommendations are not directly linked with the RSMP protocol.
The main responsibility lies with road authorities and their suppliers.

However, the RSMP Nordic partnership does have a role in supporting road authorities, e.g., by:
- Providing guidelines and case studies of how to integrate RSMP with security best practices
- Ensuring that RSMP fits well with security best practices
- Establishing and maintaining shared services/resources if needed

## What RSMP Nordic is responsible for
- Maintaining a specification that fits well with security best practices
- Providing guidelines and examples of how to use RSMP
- Maintaining test tools for verifying RSMP implementations
- Ensuring that test tools can be used together with security best practices like TLS

## What RSMP Nordic is not responsible for
- Collecting or describing security best practices
- Ensuring that road authorities or suppliers follow best practices
- Networks or embedded devices
